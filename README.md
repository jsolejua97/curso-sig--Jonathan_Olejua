# curso-sig--Jonathan_Olejua

Trabajos del curso Servicios SIG y Sitios Web (Maestría SIG, UJdeC).

## Cómo se ejecuta (instrucciones)

Los archivos y ejercicios se desarrollan siguiendo las indicaciones del curso.

## De dónde salen los datos

Archivo de hospitales de Boyacá descargado en el ejercicio anterior y almacenado en `datos/hospitales_boyaca.geojson`.

## Objetivo del repositorio

Organizar y versionar los ejercicios prácticos de SIG y desarrollo web, utilizando Git y GitHub para registrar los cambios del proyecto.

## Estructura del proyecto

- `README.md`: descripción e información del repositorio.
- `.gitignore`: archivos y carpetas que Git debe ignorar.
- `datos/`: archivos geográficos utilizados en los ejercicios.
